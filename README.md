# HR Systems

Учебный проект для изучения Python, ООП и SQLite. Цель проекта — создать простую HR-систему для управления сотрудниками, отделами, должностями и проектами.

**Текущая версия:** Alpha 0.7.1  
**Статус:** стабильная рабочая версия

## Возможности

- CRUD-операции для отделов, должностей, сотрудников и проектов
- Назначение сотрудников на проекты
- Связь сотрудников и проектов «многие ко многим»
- Консольный интерфейс (CLI)
- Хранение данных в SQLite

## Технологии

- Python 3.12+
- SQLite
- ООП

## Установка и запуск

Создайте виртуальное окружение:

```bash
python -m venv venv
```

Активируйте его:

```bash
# Windows
venv\\Scripts\\activate

# Linux / macOS
source venv/bin/activate
```

Запустите приложение из корневой папки проекта:

```bash
python main.py
```
