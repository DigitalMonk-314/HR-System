# Changelog

История заметных изменений проекта HR Systems.

## 0.7.1 — 19.07.2026

### Исправлено
- Синхронизированы сигнатуры методов между `main.py` и `DatabaseManager`.
- Добавлены недостающие методы: `get_positions_by_department`, `get_employees_by_department`, `get_employees_by_position`, `get_employees_in_project`.
- Исправлены несоответствия имён методов (`get_position`, `assign_employee_to_project`).

### Изменено
- Добавлены подробные комментарии к методам в `db_manager.py`.
- Обновлён `README.md`.
- Проект приведён в стабильное рабочее состояние.

## 0.7.0 — 17.07.2026

### Добавлено
- Первый рабочий релиз HR Systems.
- Полный CRUD-функционал.
- Консольный интерфейс.
- Управление отделами, должностями, сотрудниками и проектами.
- Связь сотрудник ↔ проект.
- Автоматическое создание структуры базы данных.
- Тесты для основных операций.

## 0.6.0 — 16.07.2026

### Добавлено
- Меню отделов.
- Меню должностей.
- Меню сотрудников.
- Меню проектов.
- Интеграция CRUD-операций в консольный интерфейс.

## 0.5.0 — 15.07.2026
