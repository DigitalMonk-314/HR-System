# План и состояние проекта

## Назначение

HR Systems — учебный проект для изучения Python, ООП и SQLite. Цель — создать простую HR-систему для управления отделами, должностями, сотрудниками и проектами.

## Текущий статус

**Версия:** Alpha 0.7.1  
**Состояние:** стабильная рабочая версия; основные функции реализованы.

На текущий момент:

- Спроектированы сущности и структура базы данных.
- Создана UML-диаграмма классов.
- Реализованы модели и `DatabaseManager`.
- Добавлены SQL-таблицы и работа с SQLite.
- Реализованы CRUD-операции для основных сущностей.
- Реализован CLI для отделов, должностей, сотрудников и проектов.
- Добавлено назначение сотрудников на проекты.
- Проведено тестирование основных операций.
- Исправлены несоответствия между CLI и `DatabaseManager`.

## Дальнейшее развитие

Предлагаемые задачи:

1. Уменьшить дублирование кода в CLI-меню.
2. Улучшить модели: перейти от кортежей к объектам там, где это оправдано.
3. Добавить валидацию пользовательских данных.
4. Рассмотреть возможность экспорта и импорта данных.
